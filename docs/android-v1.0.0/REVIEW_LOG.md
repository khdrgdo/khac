# NEXUS Android 1.0.0 — سجل جولات المراجعة الخمس عشرة

أُجريت الجولات على شجرة المستودع، ومسارات الصفحات، ومكونات الإدارة، وملفات المساعدة، وتقرير تدقيق Supabase، والتغييرات الحديثة. لا تعني الجولة أن كل عيب أُصلح؛ المخرجات تسجل ما يجب الحفاظ عليه وما يمنع النقل الآمن.

1. **خريطة المستودع والمسارات:** حصر 275 مدخلاً، وتأكيد وجود مسارات auth/feed/admin/messages/profile/courses/leaderboard/saved/notifications/change-password/complete-profile/reset-password.
2. **تدفق الهوية:** مراجعة login/signup/Google OAuth/تأكيد البريد/الاستعادة/إكمال الملف/تغيير كلمة المرور؛ تثبيت تحويل الرقم الجامعي إلى @college.edu ومسار sub_admin القديم.
3. **الملفات الشخصية:** مراجعة الحقول العامة والخاصة والصور الموقعة والثيم والنشاط والرتب والخصوصية وإخفاء المشرف المساعد.
4. **الموجز والمنشورات:** مراجعة الإنشاء والأنواع والصور والمجهول والتفاعلات والحفظ والإبلاغ والبطاقة المثبتة والمرشحات.
5. **التعليقات والأسئلة:** مراجعة parent_id والردود المترابطة والمجهول والإجابة المقبولة والإشعارات وRealtime ومنع التعليق.
6. **المحادثات:** مراجعة DM/group/الأعضاء/الرسائل/القراءة/unread/block/report/leave/delete؛ كشف اعتماد RPC على user_id غير موثوق وfallback إنشاء DM غير ذري.
7. **المقررات:** مراجعة catalog/mine/details/manage، التخصص والسنة والفصل، الأستاذ، الملفات والروابط والجدول والتحديثات والنقاشات والمزامنة.
8. **النقاط ولوحة الصدارة:** مراجعة الفترات والفلاتر والمراتب وقواعد النقاط والـ triggers ومنع احتساب النقاط محلياً.
9. **قاعدة البيانات:** مطابقة 22 جدولاً، buckets، العلاقات والحقول المستخدمة في الشاشات؛ تسجيل name_change_requests كجدول مفقود/غير مثبت.
10. **RPC والأمن:** مراجعة دوال SECURITY DEFINER وتعيين الأدوار وهوية الأدمن وRLS؛ تحديد مخاطر RPCs المحادثات والـ grants.
11. **تغييرات ما بعد التدقيق السابق:** مقارنة commits 20–21 نوفمبر؛ رصد notificationLogic وcourseUpload وإزالة native notification dispatch وتعديل PostCard وMessages UI.
12. **لوحة الإدارة:** مراجعة UsersTable وReportsTab وSubAdminsTab وAddTeacherCard وBannedWordsTab وActivityLogTab وCoursesManagementTab وStatsCards وDashboardCharts وRecentActivity وNameRequestsTab.
13. **الإشعارات والوسائط:** مراجعة الدمج وإزالة التكرار والقراءة والحذف والbroadcast والملفات الموقعة وحدود الرفع؛ اكتشاف RPC الإشعارات غير المثبت.
14. **تدفقات الأدوار المتقاطعة:** ربط كل دور بما يستطيع رؤيته وتعديله، ومراجعة انتقال الإشعار إلى المحتوى، وDM من الملف، ونقاش المقرر إلى الموجز، وإجراءات المشرف.
15. **مراجعة التناقضات النهائية:** إعادة مقارنة المصدر مع تقرير التدقيق ومع آخر commits؛ عدم مساواة وجود UI بوجود backend، وعدم اعتبار helper غير مستعمل إصلاحاً، وعدم اعتماد اختبار قديم دليلاً على main الحالي.

## قائمة منع النسيان قبل كل إصدار

- [ ] كل route في الموقع له وجهة أو قرار استبعاد مبرر في Android.
- [ ] كل مكون إداري له تبويب/إجراء وصلاحية واختبار.
- [ ] كل RPC وtable/storage bucket مستخدم في UI له عقد موثق.
- [ ] كل دور اختُبر بحساب مستقل، بما فيه sub_admin بصلاحيات مختلفة.
- [ ] كل زر وmenu وdeep link ينفذ فعلاً.
- [ ] كل حالة فشل لها سلوك واضح ولا تترك بيانات نصف محفوظة.
- [ ] لا يوجد تسريب بين حسابين أو كشف هوية anonymous.
- [ ] كل Realtime channel يُغلق ويُعاد اتصاله بطريقة صحيحة.
- [ ] لا يوجد اعتماد على localStorage أو Web APIs في Android.
- [ ] لا يوجد service_role أو secret في APK.
- [ ] كل اختبار يثبت السلوك على نسخة الكود التي سيُبنى منها APK.
